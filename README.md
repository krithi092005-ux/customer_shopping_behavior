# 📊 Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **data analytics workflow**, starting from raw dataset exploration and data cleaning to SQL analysis and interactive dashboard creation.

The project uses **Python for Exploratory Data Analysis (EDA) and data cleaning**, **PostgreSQL for SQL-based analysis**, and **Power BI for data visualization and dashboard development**.

A detailed **analytical report** and **presentation** were also created to communicate the findings and insights.

---

## 📂 Dataset

The project uses a structured dataset containing customer and purchase-related information.

The dataset was initially loaded and analyzed using Python to understand:

* Dataset structure
* Data types
* Missing values
* Duplicate records
* Statistical distributions
* Categorical and numerical variables
* Relationships between variables

The cleaned dataset was then used for further SQL analysis and dashboard development.

## 🚀 Project Steps

### 1. Data Loading

The dataset was imported into Python using Pandas.

The initial analysis included:

* Number of rows and columns
* Column names
* Data types
* Missing values
* Duplicate records
* Basic statistical information

### 2. Exploratory Data Analysis

EDA was performed to understand the characteristics and patterns within the dataset.

Key activities included:

* Univariate analysis
* Distribution analysis
* Categorical variable analysis
* Numerical variable analysis
* Correlation analysis
* Identifying potential outliers
* Generating visualizations

### 3. Data Cleaning

The dataset was cleaned before performing further analysis.

Cleaning activities included:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Checking inconsistent values
* Standardizing categorical data
* Validating the final dataset

### 4. PostgreSQL & SQL Analysis

The cleaned dataset was imported into **PostgreSQL** for structured querying and analysis.

SQL queries were used to answer business-related questions such as:

* What is the total revenue?
* How does revenue vary by gender?
* Which customers made higher-value purchases?
* What purchasing patterns can be identified?
* How do discounts affect purchase amounts?

SQL techniques used include:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions
* `AVG()`
* `SUM()`
* `COUNT()`
* Subqueries

### 5. Power BI Dashboard

The analyzed data was connected to **Power BI** to create an interactive dashboard.

The dashboard provides visual insights through:

* KPI cards
* Charts
* Tables
* Filters and slicers
* Category-wise comparisons
* Revenue analysis
* Customer analysis

The dashboard allows users to interact with the data and explore different aspects of the dataset.
